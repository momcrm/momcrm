# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Instead, report them privately using GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/momcrm/momcrm/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected versions, and steps to reproduce it.

You can also open a report directly at https://github.com/momcrm/momcrm/security/advisories/new.

We will acknowledge your report, investigate, and keep you updated through the advisory until a fix is released.

## Supported versions

Security fixes are applied to the latest release on the `main` branch.
